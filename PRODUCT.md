# Physlib Knowledge Graph

An explorer for Physlib source modules and their directly imported Mathlib foundations. The city makes source geography and file imports spatially navigable; the Inspector provides exact module identities, source paths, line ranges and revision-pinned links.

Preserve the real directory hierarchy, three source boroughs, two rivers, module identities, navigation and dependency semantics. File imports do not establish declaration-level usage. Decorative storeys must remain distinct from source floors and exact source-line counts.

The C1 atomic architecture is opt-in through `visual=c1`. Existing Milestone C remains the default: the reported software-rendered benchmark is 35.6 FPS for C1 versus 45.3 FPS for C. Default promotion awaits approval and resolution of that regression.

C2 extends the original architecture through `visual=c2`, alongside preserved C1 and default C. Its persistent version-1 colour registry addresses 39 directory territories and three Root Modules territories; colour identifies source geography, never proof status, completeness or scientific rank. Civic landmarks, streets, bridges and trees are scenery, not source modules or import endpoints. Source data and canonical source semantics remain unchanged.

C2 adds reversible Explore mode with Files and Inspector drawers; leaving Explore restores the source-panel layout. In the controlled Software/Medium comparison, C measured 42.6 FPS, C1 36.6 FPS and C2 38.3 FPS. C2 passes the comparison gate of at least 90% of C1; this does not replace the earlier benchmark or grant default-promotion approval, which remains pending.

C3 is an ordinary opt-in presentation extension through `visual=c3`; default C and comparison C2 remain available unchanged. It preserves C2 module anchors, plots, heightmap, colour registry and graph while adding broader module silhouettes and non-module civic forecourts. The implementer selected space-age from the user's requested actual Three.js gardens/space-age concept comparison. This selection does not grant default-promotion approval. Reported software-rendering WARP checks pass their gates (37.3 FPS world, 28.4 Explore, 47.2 Low and 42.9 selected); independent visual review still identifies partial metropolis/campus grouping, and approval remains pending.
