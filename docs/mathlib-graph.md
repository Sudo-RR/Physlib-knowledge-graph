# Mathlib module data — current scope

Mathlib is not rendered as an underground or global city. Each source complex has a local station; cyan utility paths represent actual explicit direct module imports, with role links derived from cited source modules. Macro/meso cap visible paths and preserve beacons; selected complex shows exact local role links. Full Mathlib is not indexed by this interface. The scoped module data and elaborated external declaration targets are separate evidence types.

Generate with the pinned Mathlib checkout and `npm run build:mathlib` as in [Development](DEVELOPMENT.md). Artifacts `mathlib.json` and `mathlib-bridge.json` are generated. Native direct constant refs may mention external constants; inspect provenance and coverage, not inferred proof dependency. See [Architecture](ARCHITECTURE.md) and [Handover](HANDOVER.md).
