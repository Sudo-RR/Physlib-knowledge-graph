# Unified city navigation

The Geneva geometry remains the sole primary user experience. The old City v2 URL redirects to it with query/hash intact; its code remains in the repo for rollback. C.4 historical deep links remain supported explicitly, but no legacy explorer or study is linked in the main navigation. Geographic proper names are removed from flat and 3D labels, while the waterways, bridges and bank allocation remain unchanged. Labels identify actual libraries and physics subjects.

Navigation: drag pan in both views, wheel and toolbar zoom, keyboard WASD/arrows, F focus, M/Home overview, I toggle inspector, / search, Esc clear selection, 1/2/3 uses/used-by/Mathlib-only. Complex, role building and station selection share one inspector and a visible amber selection ring; focus preserves view mode. Source inspection and research tools remain. Old demo mode no longer opens the v2 renderer. Existing C.4-only links keep their historical behavior rather than pretending an exact migration exists. No changes to mathematical identities or extraction scopes. Browser CI checks the retired entry point, label removal, inspector toggle, focus/selection and flat zoom in addition to existing gates. Touch drag is supported; pinch zoom and device acceptance remain separate.
