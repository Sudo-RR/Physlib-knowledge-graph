# Full native Lean metadata

The 51-declaration pilot established exact environment identities, pretty-printed signatures, exact declaration ranges and direct type/value constants. The full extraction now runs the same Lean environment exporter across Physlib, PhyslibAlpha and QuantumInfo, streams JSONL rather than accumulating a huge output array, bounds per-signature heartbeats, and requires exact identity coverage. Raw graph extraction is uploaded before optional metadata, so a native timeout or validation failure does not invalidate the graph.

The native artifact records the same graph provenance and SHA-256 of its JSONL. The packer validates each exact identity and range, checks complete coverage, hashes the stream, deduplicates reference identities in module dictionaries, and builds content-addressed module shards (24 MiB per shard, 700 MiB total budget). Publication reruns validation from raw artifact matching the selected full graph run, and rejects mismatched Physlib, Mathlib, toolchain, extractor or raw graph hash. Only the matching module is downloaded on opening native details, with SHA-256 verification and bounded 8-module cache. No new global multi-hundred-MB download. Exact Lean direct constants are separate from routed result-graph edges; no range is fabricated, and unavailable signatures/values remain explicit.
