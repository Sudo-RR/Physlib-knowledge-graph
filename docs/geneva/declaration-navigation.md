# Declaration-level spatial navigation

The published graph is queried by exact qualified Lean ID. The global sidebar search supports names, modules and kind filters, bounded result pages; local declaration selection provides prerequisite/dependent lists and trail backtracking. Each local declaration is mapped by exact contributor module ownership. A theorem or inductive/constructor may be placed in a uniquely matching inferred role building whose module list contains the actual module; this is not a lexical identity match. Definitions and ambiguous cases land at the complex. Mathlib external nodes get pinned source module links, not invented city locations. Declaration-mode map/3D arcs are separately coloured dashed cyan/lime and aggregated per direction/remote complex, capped at 14 groups each direction; full recorded edge lists remain available. Switching to a normal complex clears the declaration mode and shareable declaration parameter. The browser restores qualified deep links on demand; data is still lazy and revision-verified. No new geometry, rendering or lighting. Edges may be routed, coverage partial and no proof certification is implied. CI tests mapping, search, aggregation, browser navigation and clearing.
