# Architectural massing and urban realism

Visual evidence from successful run 45659580986 showed a sparse diagram with very tall slender role towers and large grey margins. Production layout median role width was 2.31 units and median height 55.08 (ratio ~24:1). Render-only monotone height remapping 2.7 + 27 ((max(0,h-5))/89)^2 preserves source height and IDs, changes the visual encoding from the old linear display of logarithmic height, and brings median height to ~11.25. This does not change source size or building footprint allocation.

Additional neutral low-rise context uses a deterministic spatial clearance index and exact polygon edge buffers. Existing reserved parcels, civic buildings, road/bridge sampling, trees and parks are protected. The added lots carry no Lean IDs. Pitched roofs, roof material variation, rooftop structures, smaller facade tile scale, actual PCF sun shadows at medium/high, water bump texture and continued waterways outside the mapped region improve the physical appearance. Low quality disables shadow rendering. Camera framing is tighter and the north-up 3D pitch is reduced. Geometry still uses adaptive LOD and instancing. No new remote assets or licenses.
