# Night terrain and flowing rivers — #91
Original shader implementation; references [SynthCity](https://github.com/jeffbeene/synthcity), [procedural-city](https://github.com/thepearson/procedural-city), [cheapwater](https://github.com/mqnc/cheapwater), [Three.js flow maps](https://github.com/mrdoob/three.js/issues/10036). SynthCity's Shaders.js is a sharpening postprocess, not a terrain/water shader. Adopt concepts, not copied code/assets. Ground/asphalt use world coordinates, subdued blue-grey palette and procedural aggregate/paving; road joins derive from maximum incident source width; lane markings and warm curb highlights follow recorded segments. No layout changes. Remove contact shadow call. River has static rich base and animated translucent ripple overlay in existing GPU context; separate cheap scene with approximate box and bank depth proxies, clear depth before rendering semantic overlays. No real reflections, hydraulic simulation or exact occlusion; possible small proxy clipping and label overlap. Motion follows pause/OS reduction and visibility, no animated full-scene redraw. Unit/browser checks added; actual visual review and hardware performance pending.
