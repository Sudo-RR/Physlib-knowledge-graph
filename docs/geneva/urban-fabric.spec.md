# G2–G3 — Street-first urban fabric
Issues #60, #61. Dependency: G1 terrain acceptance. The previous random-point sampler is a prototype, not the final planner.

## A. Street network (G2)
Start with quay centerlines, bridge landings, arterial roads, major public squares and sector entrances. Connect major anchors through land-constrained paths; make arterial direction respond to river bends, peninsula shape and local landmarks. Generate secondary network per neighbourhood using a seeded weighted Voronoi/power diagram or constrained subdivision. Use candidate edges, not an unfiltered tessellation: clip to buildable land; merge near intersections; split all geometric crossings; simplify short segments; assign hierarchy, widths, turning limits and setbacks. Different neighbourhood orientations and density emerge from street topology. Avoid a global rectilinear lattice and random edges through buildings.
Represent nodes {id,x,z,kind}, edges {id,from,to,polyline,width,class,bridgeId?}. Proposed width ratios arterial:local:alley = 2.4:1.5:1; calibrate to current building scale, do not conflate units with real metres. Bridge IDs match approved terrain anchors. Ordinary streets are never allowed through water. Reserve buffers around roads and promenades. Use spatial index and polygon clipping, not O(N²) collision scans for the final full-world pipeline.
Extract planar faces by half-edge traversal or polygon difference of road buffers from buildable land; remove degenerate slivers, reserve suitable open-space faces, assign block frontage. Record all failed candidates with reason. Connectivity test: populated sectors connected by civic network; each occupied block has access; bridges terminate at actual road nodes; intersections have explicit junctions; no unsupported water crossings or roads through occupied footprints.

## B. Allocation (G3)
Inputs: full canonical City model, validated street blocks, geometry version, seed and allocation configuration. Separate immutable semantic IDs from mutable art coordinates. Per complex estimate footprint requirement for actual role buildings, station, clearances, local courtyard and frontage. Reserve capacity before assignment. For each library grow subject clusters over the block adjacency graph using seeded region growth weighted by frontage, usable capacity, proximity to previously assigned same-subject blocks and desired district density. Do not use import edges to infer subject or sector identity. Mixed blocks allowed only with explicit plot assignments and distinct building colours.
Subdivide large blocks into street-facing parcels with irregular but usable polygons. Fit complexes to one parcel or contiguous adjacent parcels with recorded membership, not uniform circular platforms. Orient buildings along frontage and courtyard geometry. Use polygon containment and collision tests for actual footprints, including station and scaffolding/crane extent. If no fit, retry alternate plots, adjust non-semantic spacing, subdivide or expand buildable area; deterministic bounded retries. Explicit error if impossible, with diagnostics, never silently skip. Preserve full-world geometry on subject filters. Maintain source ID to world transform mapping. Same source, seed and config produce identical layout; across changed snapshots prefer retaining occupied valid sites and fill reserved capacity (document when regeneration moves a complex). No unsupported promise of stable positions across arbitrary revisions.

## C. Density and urban character
Rive Gauche: denser perimeter blocks, central public squares and waterfront landmarks; Rive Droite: larger varied districts and arterial network; Outre-Arve: compact neighbourhoods and public greenery. Art direction does not imply rank or maturity of mathematics. Buildings of all roles use content-based height; vary roof forms and setbacks without changing semantics. Keep spacing visually plausible at overview and district zoom. Reserve parks as real block faces, not strips repeated at every complex. Add urban voids with purpose, avoid identical identical-size courtyards.

## D. Output contract and invariants
Layout {version,sourceRevision,seed,terrainRevision,streetGraph,blocks,parcels,complexPlacements,decorativeZones,diagnostics}. Block/parcel polygons valid and disjoint in interiors. Every complex exactly once, correct library sector, same subject as canonical source. Footprints contained in eligible parcels and disjoint from roads/water/other footprints (within documented epsilon). Each station accessible, ground dependencies remain local. Graph IDs/edges unaffected by layout. Decorative streets, bridges, buildings and parks are not graph entities.
Test synthetic skewed populations, root files, empty subject, full current snapshot, growth fixture (+25% demand), randomized seeds, repeatability, no overlap, access frontage and water clearance; report rejection rates, capacity, runtime and diagnostics. Golden reference overhead captures for G2 and G3. User acceptance required for visual morphology; numerical tests alone insufficient.
