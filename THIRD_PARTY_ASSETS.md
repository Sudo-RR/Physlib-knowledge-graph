# City art and third-party assets

The default building facades, roof shapes, entrances, trees, roads, signs and ground
colours are generated by this repository's code. The four roof
and footprint variants are visual decoration; they do not denote a Lean
declaration type, construction status, project completeness or importance.

The renderer uses Three.js, an MIT-licensed software dependency; see its
installed package licence and `package-lock.json` for the pinned version.
If external art is added later, record its author, source, licence, any
redistribution conditions and required attribution here before shipping it.

The art kit includes an orange wireframe scaffold for an explicitly supplied
construction status. Construction sites are not displayed in the current city:
the graph has no verified construction-status field. A scaffolded appearance
must not be assigned from file size, folder name or guesswork.

## Milestone B.1 generated facade

site/city-district-lod.js generates a 256x128 facade atlas in Canvas from original rectangles and colours. It contains no external image or model data. LOD shells and the transition shader are original repository code. The same CC0 five-part kit remains the only imported district architecture; its existing mirror-provenance limitation is unchanged.
